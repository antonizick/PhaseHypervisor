# Third-party notices

PhaseHypervisor currently bundles **no third-party code**. The runtime uses only the Python standard library (ADR-0010 in [docs/PHX_DECISIONS.md](docs/PHX_DECISIONS.md)).

Development tools (uv, pytest, ruff, mypy and their dependencies) arrive in Phase 02. They are used to build and test the project, are not redistributed with it, and are pinned in `uv.lock`. Each one will be listed here with its licence when it is added.
